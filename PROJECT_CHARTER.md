# PROJECT CHARTER — Taren Game Studio

## Mission

Build an AI-native PC game studio in which ChatGPT, Claude Code, Codex, and Antigravity collaborate toward shared project goals through deterministic orchestration, structured memory, adversarial review, automated testing, and a realtime visual HQ.

## Owner

Jimmy. Owner instructions override all agent plans and decisions.

## Core v0.1 objective

Prove the production machine before attempting a commercial game.

The first verification target is a deterministic FakeAgent pipeline followed by a minimal Windows Pong project.

## Non-negotiable principles

- no important work self-approved by its creator
- no state transition without an event
- event history is immutable
- bounded retries/rework
- scoped agent context
- explicit dependencies and artifacts
- human approval for spending, legal commitments, and external publishing
